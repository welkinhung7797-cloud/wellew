# WelleW 橫向作品冊

原網站：https://wellewkin.pages.dev/

以原站作品內容重建的靜態網站。首頁、10 類作品、聯絡頁共 12 頁，從左向右瀏覽。保留原作品與聯絡資訊，新增作品目錄、獨立作品播放器及每頁不同動作的簡筆巴哥。

## 本機預覽

需要 Node.js，沒有額外套件需要安裝。

```sh
npm start
```

開啟 http://127.0.0.1:4173/ 。預設僅在本機提供預覽。

## 瀏覽方式

- 下方左右箭頭、鍵盤左右鍵、滑鼠滾輪、觸控板或手机橫向滑動。
- Home / End 回到首頁或聯絡頁。
- 上方「作品目錄」直接選作品。
- 點作品封面或縮圖，開啟大圖或影片；Escape 關閉。
- Discord 頁可選擇 7 項功能。
- 每頁有獨立網址片段，可直接分享指定作品頁。

## 部署到 Cloudflare Pages

```sh
npm run build
npm run check
```

- 建置指令：`npm run build`
- 輸出資料夾：`dist`
- 純靜態檔案，不需要環境變數或伺服器端服務。
- `dist` 可以直接上傳到 Pages；請先在預覽部署確認，再替換正式網站。

目前 GitHub Pages 使用 `master` 分支的根目錄，網址為 https://welkinhung7797-cloud.github.io/wellew/ 。根目錄同時保留可直接使用的靜態入口與素材，推送後由既有 Pages 設定自動發布。

## 調整內容

- `content.js`：作品文字、媒體、經歷、聯絡資訊。
- `style.css`：版面、配色、響應式與減少動態效果。
- `app.js`：翻頁、作品目錄、延遲載入及播放器。
- `assets/pug/pose-01.svg` 至 `pose-12.svg`：12 個簡筆巴哥動作。
- `assets/source/`：原網站下載的作品素材與影片封面。

## 效能處理

首頁不建立影片播放器。只有開啟作品時才設定影片來源，關閉即暫停並釋放播放器；切到其他分頁也會暫停播放。圖片只準備目前頁面及相鄰頁面。主要翻頁使用瀏覽器原生橫向捲動與吸附，不執行逐幀的 JavaScript 捲動動畫，也没有持續循環的背景動畫。

巴哥位於每頁標題右方，原有作品介紹以副標題呈現，沒有另外的狗狗台詞。巴哥沿用 LOGO 的金黃、深炭與奶油三色，四肢收細縮短，12 頁各有不同姿勢。只在目標頁進入畫面後短暫向右跑動，支援「減少動態效果」。字型、圖像與作品均由本站提供，不依賴外部字型或前端框架。

效能檢查驗證結構和載入策略，不代表已在所有裝置測得特定 FPS。原站的客觀觀察及檔案大小記錄見 `reference/performance-audit.md`。

## 素材來源

作品素材與文字由使用者指定的原站移植，詳見 `reference/content-notes.md`。巴哥以使用者提供的風格參考與原 LOGO 配色延伸，重新繪製原創向量動作。字型採用 Noto Serif TC，授權附在 `assets/fonts/OFL.txt`。
